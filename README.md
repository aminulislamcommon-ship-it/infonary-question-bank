# 𝟙nf𝟘nary ICT — Teacher Portal Prototype

বাংলা ভাষার responsive Question Bank dashboard prototype.

## ব্যবহার
- `index.html` ফাইলটি Chrome/Edge-এ খুলুন, অথবা GitHub Pages-এ publish করুন।
- প্রশ্ন যোগ, ফিল্টার/সার্চ, প্রশ্নপত্রে প্রশ্ন নির্বাচন, Print / Save as PDF, JSON export/import রয়েছে।
- ডেটা বর্তমান ব্রাউজারের Local Storage-এ সংরক্ষিত হয়।

## সীমাবদ্ধতা
এটি static prototype, production full-stack app নয়। এতে বাস্তব authentication, cloud database, shared multi-user data, server-side permissions বা online exam submission নেই। এগুলো যুক্ত করতে backend (যেমন Supabase) এবং security policies সেটআপ করতে হবে।
